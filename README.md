## About

I build practical software across backend, frontend, mobile, automation, and live production environments.

My engineering style comes from three places: a long Yazicioglu apprenticeship period that taught hands-on ownership, physics engineering discipline that shaped how I reason about systems, and product work around AI-assisted pre-accounting, ERP, admin panels, and operational tooling.

I care about systems that are not only built, but also understood, shipped, observed, and recovered when real users depend on them.

## Current Focus

## Working Principles

- Read the existing system before changing it.
- Protect contracts between backend, frontend, and mobile clients.
- Prefer small, verifiable releases over vague rewrites.
- Keep operations close to development: logs, health checks, deploy evidence, and rollback paths matter.
- Turn field experience into calmer software decisions.
